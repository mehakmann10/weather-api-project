# Weather Application

A simple weather application built using HTML, CSS and JavaScript that fetches weather information from an external API and displays it in a clean, user-friendly interface.

## Live Demo
[View Weather App](https://mehakmann10.github.io/weather-api-project/)

## Features
- Search for weather information by city name.
- Display current temperature and weather conditions.
- View humidity and wind speed.
- Check upcoming weather forecasts.
- Dynamically update weather details based on the searched city.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Weather API

## How It Works
The application fetches weather data from an external API based on the city entered by the user. JavaScript processes the API response and dynamically displays the weather information on the webpage.
